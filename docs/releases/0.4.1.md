## CatalyX 0.4.1

A start-up release: no terminal window, and a window that appears fully drawn.

### Fixed
- **No terminal window at start-up.** `catalyx.exe` used to be a console program, so Windows (Windows Terminal, by default) opened a terminal window for it every time. It is now a window program: starting it, from a shortcut, Explorer or the one-click task, never opens one.
- **No empty window.** The window used to appear about 40 ms after launch with nothing drawn, and fill in a quarter of a second later. It is now created hidden and shown once it has drawn, about 250-285 ms after launch on the test PC. Almost all of that is Windows and the graphics driver creating the OpenGL context; CatalyX's own start-up work is a few milliseconds.
- Hardware probes (power plans, graphics card, services) now start after the window is shown, so they never compete with the first frames.

### New
- **`catalyx-cli.exe`**: the same program as a console program, for scripts, pipes and agents (a shell waits for it; exit codes, redirects and Ctrl+C behave). Commands also still work as `catalyx <command>` in a terminal. Download it next to `catalyx.exe` if you want it.
- `CATALYX_TRACE=1` records start-up timing to `%TEMP%\catalyx-startup.txt`.

### For contributors
Maintenance scripts in `scripts/`: `check.ps1` (every check, one command), `release.ps1` (check, push, CI, tag, verify), `screenshots.ps1` (steady, repeatable screenshots), `click-test.ps1` (drives the real window with the real mouse), `startup-profile.ps1`.

### Download
`catalyx.exe` (the window), `catalyx-cli.exe` (the command line). Verify each against its `.sha256` file. Windows 10/11.
